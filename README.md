# austinperez.xyz

My personal site, live at [austinperez.xyz](https://austinperez.xyz).

Built with Next.js (App Router) and Tailwind CSS, deployed on Vercel.

- `app/content.js` holds all of the copy on the home page.
- `app/page.js` lays it out.
- `app/opengraph-image.js` generates the link preview card.

```bash
npm install
npm run dev
```
